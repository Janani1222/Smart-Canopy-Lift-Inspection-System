 ##Smart Canopy Lift Inspection System

## AI-Assisted Digital Twin for Canopy Lift Inspection

### Project Overview
The **Smart Canopy Lift Inspection System** is a Python-based inspection and monitoring solution designed to simulate canopy lift measurements, identify abnormal sensor readings, and visualize inspection data using digital twin concepts.

The system uses simulated sensor data, anomaly identification, historical trend analysis, and visualization techniques to support accurate and efficient canopy inspection.

### Problem Statement
Traditional inspection processes may require manual measurement and monitoring, making it difficult to identify small deviations and track historical inspection conditions.

This project aims to develop a smart inspection system that uses sensor data simulation and digital twin visualization to improve monitoring, anomaly identification, and inspection tracking.

### Key Features
- Simulation of multiple sensor measurements.
- Monitoring of 12 sensor points.
- Measurement resolution of 0.01 mm.
- Inspection tolerance limit of 0.1 mm.
- Sensor anomaly identification.
- Digital twin visualization of canopy measurements.
- Sensor-based heatmap visualization.
- Historical measurement trend analysis.
- Canopy Health Score monitoring.
- SQLite-based inspection tracking.

### Technologies Used
- **Programming:** Python
- **Data Processing:** NumPy, Pandas
- **Visualization:** Matplotlib, Plotly
- **Database:** SQLite
- **Development Environment:** Jupyter Notebook
- **Concepts:** Digital Twin, Sensor Data Simulation, Anomaly Detection, Data Analytics

### Project Workflow
1. Generate simulated canopy sensor measurements.
2. Process and analyze sensor readings.
3. Compare measurements against inspection tolerance limits.
4. Identify abnormal sensor values.
5. Visualize sensor measurements using heatmaps and digital twin representations.
6. Analyze historical sensor trends.
7. Monitor overall canopy health.

### Expected Outcomes
- Improved visibility of sensor measurements.
- Identification of abnormal measurement patterns.
- Easy monitoring of inspection conditions.
- Historical inspection data tracking.
- Better understanding of canopy lift performance.

### Installation and Usage

Clone the repository:

```bash
git clone https://github.com/Janani1222/Smart-Canopy-Lift-Inspection-System.git
```

Navigate to the project folder:

```bash
cd Smart-Canopy-Lift-Inspection-System
```

Install the required libraries:

```bash
pip install numpy pandas matplotlib plotly
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open `Smart Canopy Lift Inspection System.ipynb` and execute the notebook cells.
